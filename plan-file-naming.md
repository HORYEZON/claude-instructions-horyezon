# Plan files get descriptive names

Name every plan file in `~/.claude/plans/` after what it plans, in lowercase snake_case: `guitar_tools_metronome.md`, `guitar_tools_pedals_special_effects.md`. Prefix the project name when it isn't obvious (e.g. `kalamari_site_design_port.md`).

Plan mode hands out a random name (e.g. `harmonic-sprouting-koala.md`). **Rename it with `mv` as soon as the plan is approved**, and cite only the new path in memories and messages.

Never reuse one plan file for a second plan. Plan mode keeps handing back the session's same random file. Before writing a new plan into it, move the old plan to its own descriptive name.

**Why:** the owner, 10/25/26, found the random names "bizarre, hindi related mismo sa contents". A reused random file had also overwritten a shipped plan.
